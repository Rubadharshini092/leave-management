# Leave Management Frontend
React + Vite frontend for the Leave Management Website.

## Local setup
1. Run `npm install`.
2. Set `VITE_API_URL=http://localhost:5000/api` in `.env`.
3. Run `npm run dev`.

## Vercel deployment
- Root Directory: `frontend`
- Build Command: `npm run build`
- Output Directory: `dist`
- Environment Variable: `VITE_API_URL=https://YOUR-RENDER-BACKEND.onrender.com/api`
